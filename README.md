# APA1 Supa Task Backend - Personal Book Library 

## Project Overview
This is the backend for the APA1 Supa Task. It is a personal book library that allows users to add books to their library and view them. It supports the front-end React.js Express application and is using Supabase for:
- Database hosting for storing application data (PostgreSQL).
- Authentication for user login and registration for security. 
- Autogenerated API endpoints for CRUD operations.  
- Real time data synchronisation.

## Prerequisites for using/running this project

- [Node.js](https://nodejs.org/) (v16 or newer)
- [Supabase CLI](https://supabase.com/docs/guides/cli)
- [curl](https://curl.se/) for testing functions locally

## Setup and Running App 
1. Install dependencies: Run `npm install` in your terminal to install all necessary dependencies.
2. To start local Docker-based Supabase instance - run `npx supabase start` in the backend project terminal to start the server. If not signed in `npx supabase login` must be run first to authenticate. 
3. If connection between the project is lost, run `npx supabase link --project-ref <project-ref>` to link the project to the local instance, and enter password when prompted. 
3. Then open the front end application (GITHUB LINK) and run:
 - `Node server.js` in your terminal to get the express server running with the 8080 port. 
 - Open a second terminal and run `Npm start` to get the react app running with the 3000 port to ensure both are running in sync. 
4. Open your web browser and navigate to `http://localhost:3000` to access the React application to view the application.
